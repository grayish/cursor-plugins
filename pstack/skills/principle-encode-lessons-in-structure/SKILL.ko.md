# 교훈을 구조에 새기기

교훈에 판단이 필요해서 구조로 구현할 수 없다면, 지시를 더 눈에 띄게 만들고 실패 사례를 예시로 추가합니다.

**따름 정리:** 구조적인 해결책이 있다면 구조적인 해결책만 씁니다. 지시는 증상일 뿐입니다.
