# 탐색자(explorer) 프롬프트 템플릿

각 탐색자 서브에이전트의 프롬프트는 이 템플릿으로 만듭니다. 자리 표시자를 채우세요.

---

다른 탐색자들이 같은 하위 시스템의 다른 부분을 병렬로 조사하고 있습니다. 모든 것을 다루려고 하지 마세요. 할당받은 관점에 집중하고 깊이 파고드세요.

## 질문

> {QUESTION}

## 당신의 탐색 관점

{EXPLORATION_ANGLE}

## 출력

### 찾은 구성 요소
핵심 타입, 서비스, 클래스, 추상화를 적습니다. 각각에 대해 이름, 파일 경로, 그리고 무엇을 하는지 설명하는 한 문장을 적습니다.

### 흐름
실행 흐름을 단계별로 적습니다. 각 단계마다 어떤 함수/메서드가 실행되는지, 어느 파일에 있는지, 무엇을 하는지, 다음에 무엇을 호출하는지를 적습니다. 단계 사이에 전달되는 데이터도 포함합니다.

### 읽은 파일
탐색하면서 읽은 모든 파일을 적습니다. 설명자(explainer)가 이 파일들을 참조할 수 있도록 하기 위해서입니다.

### 경계
이 하위 시스템이 코드베이스의 다른 부분과 연결되는 지점을 적습니다. 입력과 출력을 적습니다.

### 명확하지 않은 점
놀랍거나, 과거 사정 때문에 그렇게 된 것이거나, 잘못 이해하기 쉬운 것을 모두 적습니다. 한 방식으로 동작할 것처럼 보이지만 실제로는 다른 방식으로 동작하는 것들을 적습니다.

### 남은 질문
완전히 추적하거나 이해하지 못한 것을 모두 적습니다. 빈틈이 있으면 솔직하게 밝히세요.
