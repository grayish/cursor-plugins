# 제1원칙에서 다시 설계하기

변경을 통합할 때 기존 설계에 덧붙이지 않습니다. 그 요구사항이 처음부터 기본 전제였던 것처럼 다시 설계합니다.

- 영향을 받는 파일을 모두 읽고 현재 설계를 이해합니다
- "이 새 요구사항을 안고 처음부터 작성한다면 무엇을 만들까?"라고 질문합니다
- 변경을 모든 참조에 반영합니다: 타입, 문서, 예시, 근거 섹션
- 재설계 전체를 생각한 뒤, 점진적으로 전달합니다

이것은 기존 설계에 변경을 통합하면서 선택의 여지를 보존하는 방법입니다.
