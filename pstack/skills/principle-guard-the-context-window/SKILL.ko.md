# 컨텍스트 윈도우를 지키기

**이유:** 컨텍스트가 넘치면 추론 품질이 떨어지고, 압축으로 인한 왜곡이 생기고, 진행이 멈춥니다.

**패턴:**
- **단계의 크기를 정하고 범위를 제한합니다.** 단계마다 파일 수를 제한하고, 턴 예산을 정하고, 각 방식에 드는 비용을 계산에 넣습니다.
