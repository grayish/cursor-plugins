# 호출자를 마이그레이션한 뒤 레거시 API를 삭제하기

- 테스트가 새 계약을 검사하도록 갱신하고, 리팩터링 이전의 구현 세부 사항만 보호하던 테스트는 삭제합니다

**적용되는 경우:**
- 하위 호환성에 의존하는 외부 사용자가 없습니다
- 프로젝트가 조율된 호환성 깨짐 변경을 감당할 수 있습니다
- 새 API가 단순화나 리팩터링 작업의 일부입니다
